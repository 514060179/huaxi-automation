# 真实环境集成测试 harness

直接调用真实后端接口、使用手动提供的 token、按正常路径完成课程学习和微信认证的测试程序。

## Language

**正常路径**：
从获取任务列表到触发微信认证、扫码验证、恢复学习的合法业务链路；不包含绕过或攻击行为。
_Avoid_: 攻击链路、旁路

**集成测试 harness**：
本子项目中的自动化测试程序，负责按正常路径调用真实后端接口。
_Avoid_: 模拟器、爬虫

**二维码页面**：
当真实接口返回 `needPoint: true` 时，由 harness 本地生成的扫码页面，显示认证二维码并轮询验证结果。
_Avoid_: 登录页

**学习会话**：
harness 一次完整运行所对应的状态集合，包括选中的任务、课程、小节、心跳、认证状态和视频分片进度。
_Avoid_: 抓包会话

**心跳上报**：
学习过程中按真实时间间隔提交 `docPlayTime`、`lastTime`、`studyToken` 等字段的接口调用。
_Avoid_: 定时任务

**监管状态机**：
围绕 `IN_PROGRESS`、`PAUSED`、`PENDING`、`VERIFIED` 的课程学习与认证状态转换。
_Avoid_: 流程状态
