# 华夏会计网微信认证链路抓包 Runbook

会话编号：`huaxia-kuaiji-auth-flow-001`

## 前置条件

- macOS
- Charles 已安装
- Charles 根证书已安装并在钥匙串中设为“始终信任”
- `Proxy → macOS Proxy` 已开启
- `Proxy → SSL Proxying Settings` 已启用，`Host: *`、`Port: 443`
- 已确认桌面微信中的目标小程序请求能出现在 Charles 中

## 录制范围

从打开目标小程序开始，一直录到微信认证完成、小程序页面稳定为止。中间不要停止或清空 Charles。

## 用户路径

1. 在桌面微信中打开“华夏会计网”小程序。
2. 进入课程首页，打开唯一带“专业课”字眼的课程。
3. 点击列表中的“开始学习”。
4. 出现需知悉提示后，点击“已知晓，前往学习”。
5. 进入课程小节列表，选择一个小节开始观看视频。
6. 保持播放约 30–60 分钟，不要拖动进度条。
7. 当小程序内出现微信认证二维码时，用手机微信扫码并完成认证。
8. 继续等待，直到小程序加载稳定。
9. 停止 Charles 录制。

## 数据保存

保存到本目录：

- Charles 原生会话文件，建议命名 `001.chls`
- 如可导出：`001.chlsj`
- 如可导出 CSV/请求列表：`001.csv`

原始数据仅保留在本地，不需要脱敏。

## 最长等待

如果视频播放到 60 分钟仍未出现认证二维码，先停止录制并保存已捕获流量，再回来分析是否需要重跑。

## 完成后

保存文件后，把本目录里的文件路径告诉 agent，继续做接口清单、调用时序和认证链路分析。
